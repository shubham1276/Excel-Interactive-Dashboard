# ✈️ Airline Revenue & Performance Analytics Dashboard

## 📊 Project Overview

The **Airline Revenue & Performance Analytics Dashboard** is an interactive Microsoft Excel dashboard designed to analyze airline revenue, ticket sales, passenger volumes, routes, fare classes, flight performance, and anomalies.

The project transforms raw airline transaction data into an interactive Business Intelligence dashboard using Excel PivotTables, PivotCharts, KPIs, slicers, and data visualization techniques.

---

## 🎯 Objectives

The main objectives of this project are to:

* Analyze overall airline revenue performance
* Track ticket sales and passenger volumes
* Compare revenue across different routes
* Analyze revenue contribution by fare class
* Identify yearly and monthly revenue trends
* Analyze flight-level performance
* Monitor passenger utilization
* Identify unusual records and operational anomalies
* Provide an interactive dashboard for business decision-making

## 📁 Dataset

The dataset contains **260 airline records** covering the period from **2023 to 2026**.

### Dataset Columns

| Column             | Description                  |
| ------------------ | ---------------------------- |
| Year               | Transaction/flight year      |
| Month              | Transaction/flight month     |
| Date               | Transaction/flight date      |
| Route              | Origin-destination route     |
| Flight Number      | Flight identifier            |
| Fare Class         | Economy, Business or Premium |
| Tickets Sold       | Number of tickets sold       |
| Passengers         | Number of passengers         |
| Average Fare (INR) | Average ticket fare          |
| Revenue (INR)      | Revenue generated            |
| Anomaly            | Identified unusual condition |

## 🔍 Key Business Insights

### Revenue Growth

Revenue increased from approximately **₹62.82 Cr in 2023** to **₹96.05 Cr in 2026**.

### Top Revenue Route

**BOM-DEL** generated approximately **₹81.71 Cr**, the highest revenue among the six routes.

### Fare Class Contribution

Economy generated approximately **₹215.69 Cr**, followed by Premium at approximately **₹57.30 Cr** and Business at approximately **₹31.23 Cr**.

### Highest Revenue Month

August generated approximately **₹34.93 Cr**, the highest monthly revenue in the dataset.

### Passenger Utilization

The dataset contains **35,195 tickets sold** and **33,298 passengers**, resulting in an overall passenger/ticket ratio of approximately **94.61%**.

### Anomaly Monitoring

18 records were flagged with anomalies:

* 7 low-load-factor records
* 6 high-fare records
* 5 route-cancellation records
